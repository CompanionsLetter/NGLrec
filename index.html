Ce este HTML?

Bazele limbajului de marcare a paginilor web

Definiție

HTML (HyperText Markup Language) este limbajul standard pentru crearea paginilor web. Descrie structura și conținutul unei pagini prin intermediul unor etichete speciale numite tag-uri.

HTML nu este un limbaj de programare — el nu conține logică, variabile sau algoritmi. Este un limbaj de marcare: îi spune browser-ului cum să afișeze conținutul.

Scurt istoric

HTML a fost creat în 1989 de Tim Berners-Lee la CERN (laboratorul european de fizică), cu scopul de a permite schimbul de documente între oameni de știință.

Standardul este gestionat de W3C (World Wide Web Consortium). Versiunile principale: HTML 2.0 → 3.0 → 3.2 → 4.0 → 4.01 → HTML5 (cel mai recent).

Cum funcționează un TAG?

Un tag este o comandă HTML scrisă între < și >. Există tag-uri pereche (cu deschidere și închidere) și tag-uri singulare.

HTML — tag-uri
<!-- Tag pereche: are deschidere și închidere -->
<p>Acesta este un paragraf.</p>

<!-- Tag singular: nu are tag de închidere -->
<br>   <!-- salt la linie nouă -->
<hr>   <!-- linie orizontală -->
<img src="poza.jpg">   <!-- imagine -->
💡
Tag-urile pot fi scrise cu litere mici sau mari: <HTML> = <html> = <Html>. Convenția modernă este litere mici.
Atributele tag-urilor

Un tag poate avea atribute — proprietăți suplimentare ce modifică comportamentul sau aspectul elementului:

Sintaxă atribute
<eticheta atribut1="valoare1" atribut2="valoare2">

<!-- Exemplu real -->
<body bgcolor="blue" text="white">

Structura documentului HTML

Anatomia unui fișier HTML corect construit

Scheletul de bază

Orice pagină HTML respectă aceeași structură fundamentală:

structura-de-baza.html
<html>
  <head>
    <title>Titlul paginii mele</title>
  </head>
  <body>
    Conținutul vizibil al paginii apare aici.
    <p>Un paragraf de text.</p>
  </body>
</html>
<html>— rădăcina documentului
├─ <head>— informații despre pagină (nu sunt afișate)
│ └─ <title>— titlul din bara browser-ului
└─ <body>— tot ce vede utilizatorul
Tag-ul <head>

Secțiunea <head> conține metadate — informații despre pagină care nu se afișează direct în browser:

TagRolExemplu

<meta>Metadate (codificare, autor, descriere)<meta charset="UTF-8">
<link>Legătură către fișiere externe (CSS)<link rel="stylesheet" href="stil.css">

Tag-ul <basefont>

Setează fontul implicit pentru întreaga pagină de la acel punct înainte:

Formate multimedia

Formate audio comune:

.wav — WAVE (Windows, universal) .mp3 — MPEG Audio (popular) .mid — MIDI (note muzicale) .rm — RealAudio .aif — AIFF (Apple)

Formate video comune:

.avi — Audio Video Interleave (Microsoft) .mpg — MPEG (universal) .wmv — Windows Media .mov — QuickTime (Apple) .swf — Flash (Shockwave)
Tag-ul <object> pentru multimedia

W3C recomandă folosirea <object> pentru inserarea conținutului multimedia:

object multimedia
<object data="video.avi" type="video/avi"
        width="400" height="300">
  Browser-ul nu suportă acest format.
</object>
💡
Se mai pot folosi și <embed> (Netscape + IE) sau <bgsound> (IE), dar W3C recomandă <object>.

Referințe interne (ancore)

Poți sări la o secțiune din aceeași pagină:

ancore interne
<!-- Pasul 1: definești ancora (destinația) -->
<a name="sectiunea2"></a>
<h2>Secțiunea 2</h2>

<!-- Pasul 2: creezi linkul care sare la ancoră -->
<a href="#sectiunea2">Sari la Secțiunea 2</a>
Link pe o imagine

O imagine poate fi clickabilă dacă este plasată în interiorul unui tag <a>:

  <img src="logo.png" alt="Logo" border="0">
</a>

Entități HTML (&-consecutivități)

Caractere speciale și diacritice în HTML

De ce sunt necesare entitățile?

Caracterele < și > sunt interpretate de browser ca început/sfârșit de tag. Pentru a le afișa pe ecran, trebuie folosite entități HTML:

Entități de bază

&gt;    → afișează: >
&amp;   → afișează: &
&quot;  → afișează: "
&nbsp;  → spațiu non-breaking (nu se rupe la capăt de rând)
&copy;  → afișează: ©
&reg;   → afișează: ®
&trade; → afișează: ™
&euro;  → afișează: €
